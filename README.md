
# Simple Calculator

![Пример работы калькулятора](docs/img.png)

Консольный калькулятор на Java. Считывает первое число, операцию и второе число, выполняет вычисление и выводит результат. Работает в режиме непрерывного диалога — результат предыдущей операции становится
первым операндом следующей.

## Возможности

- Арифметические операции: сложение (`+`), вычитание (`-`), умножение (`*`), деление (`/`)
- Постоянная работа: результат автоматически используется как первый операнд для следующей операции
- Сброс результата командой `C` (регистр не важен: `c`/`C`)
- Выход из программы командой `S` (регистр не важен: `s`/`S`)
- Валидация ввода: некорректные числа и операции запрашиваются повторно
- Обработка деления на 0: выводится сообщение об ошибке, результат не изменяется

## Запуск

\`\`\`bash
javac -d out src/*.java
java -cp out Main
\`\`\`

## Структура проекта

- `Main.java` — точка входа
- `Calculator.java` — основной цикл калькулятора и арифметика
- `ConsoleInput.java` — чтение и валидация ввода с консоли
- `AppState.java` — состояние работы приложения (`START` / `EXIT`)
- `CalculationsState.java` — состояние вычислений (`CLEARED` / `CALCULATED`)
